Настройки отклика

Значения по умолчанию для вопросов работодателя. Их можно будет переопределить для конкретной вакансии.

Языковая модель

Ключ шифруется перед сохранением в базе и никогда не показывается обратно. Для матчинга и генерации материалов настраивается своя модель: получите список доступных моделей, выберите одну и сохраните.

Матчинг

Модель для извлечения требований, декомпозиции навыков и оценки соответствия резюме.

Генерация материалов

Модель для сопроводительных писем, ответов на скрининг и анализа резюме.

Очередь матчинга

Очередь задач перерасчёта матчинга, которые обращаются к локальной модели. «Остановить» запрещает воркеру брать новые задачи. «Очистить» останавливает обработку, отменяет все ожидающие задачи и прерывает зависшие. «Продолжить» снова запускает обработку.

Сессии сайтов

Вход выполняется вручную в Chromium на локальном браузерном экране. Приложение не получает пароль, код подтверждения или CAPTCHA — сохраняются только зашифрованные cookies и состояние сайта.

Подключение почты по IMAP

Используйте отдельный пароль приложения. Пароль сохраняется только в зашифрованном виде, содержимое писем не сохраняется.

Сопоставление полей сайта

Выберите добавленный сайт, сопоставьте найденные поля с общими данными профиля и при необходимости задайте значение только для сайта или отдельного поля.

Резюме

Можно хранить несколько резюме. Навыки, ключевые слова и сводка опыта сохраняются отдельно для каждого файла. Выбранное резюме используется для поиска, оценки и сопроводительных писем.

Локации

Через запятую, например: Москва, Санкт-Петербург. Оставьте пустым для поиска везде.
