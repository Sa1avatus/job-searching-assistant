Личный кабинет

Поиск и отклик на вакансии

0. Доступ

API-ключ (если сервис настроен без ключа — оставьте пустым). ID пользователя сохраняется в браузере.

1. Резюме

PDF или DOCX. Мы извлечём текст и попросим модель выделить навыки и суммировать опыт — вы всё сможете поправить перед сохранением.

2. Локации

Через запятую, например: Москва, Санкт-Петербург. Оставьте пустым для поиска везде.

3. Поиск

Ищем на hh.ru по вашим подтверждённым навыкам, создаём черновики откликов с подобранным сопроводительным письмом.
