API-ключ (если сервис настроен без ключа — оставьте пустым). ID пользователя сохраняется в браузере.

Языковая модель

Ключ шифруется перед сохранением в базе и никогда не показывается обратно. Получите список доступных моделей, выберите одну и сохраните.

Сессии сайтов

Вход выполняется вручную в Chromium на локальном браузерном экране. Приложение не получает пароль, код подтверждения или CAPTCHA — сохраняются только зашифрованные cookies и состояние сайта.

Резюме

Можно хранить несколько резюме. Навыки, ключевые слова и сводка опыта сохраняются отдельно для каждого файла. Выбранное резюме используется для поиска, оценки и сопроводительных писем.

Локации

Через запятую, например: Москва, Санкт-Петербург. Оставьте пустым для поиска везде.
