Поиск и отклик на вакансии

0. Доступ

API-ключ (если сервис настроен без ключа — оставьте пустым). ID пользователя сохраняется в браузере.

1. Языковая модель

Ключ шифруется перед сохранением в базе и никогда не показывается обратно. Получите список доступных моделей, выберите одну и сохраните.

2. Сессии сайтов

Вход выполняется вручную в отдельном окне Chromium. Приложение не получает пароль, код подтверждения или CAPTCHA — сохраняются только зашифрованные cookies и состояние сайта.

3. Резюме

PDF, DOCX, DOC, TXT, RTF, ODT, HTML или Markdown. Мы извлечём текст и попросим выбранную модель выделить навыки и суммировать опыт.

4. Локации

Через запятую, например: Москва, Санкт-Петербург. Оставьте пустым для поиска везде.

5. Поиск

Ищем через управляемый браузер, а не API. Перед поиском авторизуйтесь на выбранных сайтах в разделе выше.
